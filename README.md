### 👋 À propos

Depuis 2022, je conçois et livre en remote des **SaaS, plateformes de réservation et applications mobiles** pour des startups, PME et agences, de l'architecture à la mise en production.

- 🟢 **Disponible pour de nouvelles missions freelance** · remote depuis Madagascar (UTC+3, horaires compatibles Europe)
- 🧪 Qualité mesurable : tests automatisés, CI/CD, revues de code (1 767 tests sur un seul projet)
- 🤖 Développement augmenté par l'IA : chaînes agentiques avec Claude Code et MCP, du ticket à la PR fusionnée
- 🇬🇧 *Freelance Full Stack developer building SaaS products, booking platforms, Stripe payments and mobile apps. Open to remote projects.*
